# Python Cybersecurity Projects

A collection of Python projects I'm building as a Computer Science student to practice programming, networking, and cybersecurity concepts.

## Projects

### 1. Cybersecurity Log Analyzer
**File:** `log_analyzer.py`

Analyzes log files to help identify suspicious login attempts and possible security concerns.

### 2. Network Port Scanner
**File:** `port_scanner.py`

Checks specified systems for open network ports to help understand network services and basic security testing.

### 3. Medical Device Network Monitor
**File:** `medical_device_monitor.py`

Explores how Python can be used to monitor network connections involving medical devices and identify potentially suspicious activity.
